# John Robert R. Rogel — Portfolio

Personal portfolio built with React, Vite, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Deploy on GitHub

1. Log in to GitHub (use **rogeljohnrobert21@gmail.com**):
   ```bash
   gh auth login
   ```
2. Create the repo and push:
   ```bash
   gh repo create portfolio --public --source=. --remote=origin --push
   ```
3. Enable GitHub Pages:
   - Repo → **Settings** → **Pages**
   - **Build and deployment** → Source: **GitHub Actions**

Live site: `https://YOUR_GITHUB_USERNAME.github.io/portfolio/`
